# Sales Prediction

## Project Overview
Predicting future sales using historical data.

## Objective
To forecast sales based on previous trends.

## Dataset
Sales dataset with advertising and revenue information.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Model Used
- Linear Regression

## Key Insights
- Advertising spend increases sales
- Strong correlation between marketing and revenue
